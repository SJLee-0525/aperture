## 계획과 달랐던 것

1. **`admin-shell` 을 eslint `platform` 으로 등록해야 했다.** boundaries 규칙이 feature→feature
   import 를 막아 여섯 목록이 공용 셸을 볼 수 없었다. 열네 개 admin feature 가 소비하는 횡단
   계층이라 `dev-blog` 와 같은 성격이다. 계획에 없던 설정 변경이다.
2. **C14 가 C12 에 흡수됐다.** `AdminSortableList` 를 만들 때 `KeyboardSensor` 와 한국어
   `announcements` 를 함께 넣는 것이 자연스러웠다. 셸을 먼저 만들고 센서를 나중에 더하면 같은
   파일을 두 번 연다.
3. **행을 두 층으로 나눴다.** 계획은 `AdminSortableRow` 하나였는데 `useSortable` 이
   `SortableContext` 를 전제해 조건부로 부를 수 없다. 정렬이 없는 블로그 목록을 받으려면
   `AdminRow`(마크업)와 `AdminSortableRow`(dnd 얹기)로 나눠야 했다.
4. **ARCH-A-19 를 18개소에서 멈췄다.** 설정 편집기 다섯은 setter 가 `(lang, value)` 를 받는 명령
   계층이라 `LocalizedText` 하나를 넘길 수 없다. 훅 계약까지 바꿔야 해서 넣지 않았다. 3~4필드가
   한 격자에 들어간 곳은 쌍만 떼면 배치가 깨진다.
5. **C3 이 회귀 두 개를 남겼고 사용자가 화면에서 찾았다.** `DevTimelineRow.module.css` 를 빌려
   쓰는 `DevAwardRow`·`DevEducationRow` 가 `.move`·`.delete` 를 잃어 CSS 없이 렌더됐다. 파일 이름이
   `*Row.module.css` 가 아니어서 일괄 처리에서 빠졌다. 마지막 커밋에서 함께 고쳤다.

## 새로 찾은 것

- `RagStaleBanner.module.css` 는 소비자가 둘이다(`RevalidateFailureBanner` 가 같은 파일을 쓴다).
  죽은 클래스 참조를 이으면서 그 사실을 CSS 주석에 남겼다.
- 블로그 목록의 고정 배지가 로컬 클래스로 공용 배지의 `padding` 을 덮고 있었다. 두 CSS 모듈이
  같은 속성을 다투면 주입 순서가 승자를 정한다. 배지 스타일을 한 파일로 모았다.
- 프로젝트 배열 행의 삭제 버튼이 `padding-top` 으로 위치를 맞추고 있었다. 행이 `flex-start` 라
  모바일에서 격자가 두 줄이 되면 어긋난다.
- 관리자 사진 목록 투영에 `tags` 가 없어 태그 사용 수를 셀 수 없었다. `AdminPhotoListItem` 에
  더했다. id 문자열 배열이라 payload 부담이 없다.

## 유지·이월 판정

1. **브라우저 뒤로가기는 보호되지 않는다.** App Router 에 이동을 막는 API 가 없다. `onNavigate`
   도 수식키 클릭·외부 URL·`download` 에서는 돌지 않는다. 훅 JSDoc 에 적었다.
2. **업로드 취소를 넣지 않았다.** `browser-image-compression` 은 signal 을 받지만 Storage 업로드
   중단은 보장되지 않아 부분 취소가 된다.
3. **UI-A-13 의 WCAG 2.5.8 위반 단정을 채택하지 않았다.** 2.5.8 에는 간격 예외가 있다.
   "여유가 없는 치수" 로 문서에 기록했다.
4. **UI-A-19 의 `NaN` 주장을 기각했다.** `type="number"` 의 값 위생 알고리즘상 `.value` 가 빈
   문자열을 돌려주므로 `NaN` 은 만들어지지 않는다. 실제 문제는 `0` 이었다.
5. **UI-A-10 의 `border-radius` 근거를 기각했다.** `--r-sm` 이 `0px` 이라 실제 모서리는 같았다.
6. **UI-A-27 의 320px 넘침을 유지 판정했다.** 실측에서 넘치지 않는다. 여유가 0 이라는 사실은
   CSS 주석에 남겨 그 줄에 요소를 더할 때 다시 재게 했다.
7. **블로그 편집기 CSS 를 공용 폼 골격에 합치지 않았다.** 전폭 2단 + sticky 액션 바가
   `docs/admin-ui-conventions.md` 의 의도적 예외다.
