## 지금 고칠 5가지

전부 관측 가능한 결함이고 전부 한 파일 국소 수정이다.

1. **첫 페인트 섹션 색이 항상 파랑이다.** `theme-script.ts:12` 가 로케일 프리픽스를 벗기지 않아
   `/ko/music` 이 어떤 섹션 프리픽스와도 매칭되지 않는다. 음악·개발·연락 페이지가 하드 로드마다
   파랑으로 그려졌다가 hydration 후 제 색으로 튄다. → [02](02-correctness.md#높음-1)
2. **관리자 화면의 날짜 기본값이 DB에 굳는다.** 공개 디코더는 없는 날짜를 epoch로, 관리자 디코더는
   `new Date()`(지금)로 읽는다. 썸네일 마이그레이션이 문서를 통째로 되쓰기 때문에 실행 시각이
   촬영일·공연일로 영구 저장된다. → [02](02-correctness.md#높음-2)
3. **관리자가 빈 줄을 넣으면 챗봇 문맥이 잘린다.** 소개·헤드라인에 Enter 두 번이면 그 섹션의
   나머지가 통째로 버려진다. `heroLead` 에서 발생하면 개발 섹션 전체가 사라진다.
   → [02](02-correctness.md#높음-3)
4. **`--text-4` 대비가 두 테마 모두 기준 미달이다.** 라이트 2.56:1, 다크 3.07:1. 모바일 하단 탭바
   라벨 4개 중 3개가 상시 이 색이다. → [03](03-public-ui.md#접근성)
5. **정의되지 않은 CSS 토큰을 참조한다.** `--text-1` 이 사진 상세 공유 버튼의 포커스 링을 실제로 없앤다.
   `--s-0` 은 3곳에서 무증상이지만 같은 부류다. → [03](03-public-ui.md#css-토큰)

## 잘하고 있는 것

11개 보고서 중 3개 이상에서 독립적으로 확인된 것만 적는다.

- **import·레이어 위생.** 623개 비테스트 파일에서 `../` 상대 import 1건(구조적 예외), barrel 0건,
  `features→app`·`components→features`·`lib→features` 역방향 0건.
- **CSS 토큰 규율.** `.module.css` 156개 전체에서 hex 직박 0건. 남은 문제는 이 규율의 예외지 부재가 아니다.
- **공개 UI 문자열이 사전을 100% 경유한다.** 공개 JSX의 한국어 리터럴이 1건뿐이다.
- **테스트가 형식적이지 않다.** `toHaveBeenCalled*` 가 전체 단언의 12.9%, 스냅샷 0건.
  "깨지면 갱신" 안티패턴이 없다. 문제는 품질이 아니라 범위다.
- **E2E가 예상보다 촘촘하다.** `locale.e2e.ts` 하나가 307 협상·쿠키 우선순위·캐시 헤더·308 무체인·
  hreflang·canonical을 전부 단언한다. 이 파일 때문에 "미검증"이라던 주장 2건이 기각됐다.
- **인증 경계가 견고하다.** `service_role` 미사용, JWT 단일 클레임, 무인증 쓰기 경로 0건.
- **올바른 형태가 이미 저장소 안에 있다.** 타입 없는 JSDoc, 로컬 토큰에 담은 색, `<div aria-hidden>`
  스크림 모두 어딘가에 제대로 된 예가 있다. 남은 일은 확산이지 발명이 아니다.
