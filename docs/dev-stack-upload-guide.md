# `/dev` 기술 스택 업로드 가이드

관리자 페이지: `/admin/dev/config`

각 카테고리에서 기술명을 입력하고 `배경`, `글자` 색상에 아래 HEX 값을 넣는다. RGB 값은 색상 확인 및 다른 입력 UI용이다. 현재 관리자 색상 선택기는 HEX 형식(`#RRGGBB`)으로 저장한다.

## 저장 순서

1. `/admin/dev/config`에 로그인한다.
2. 위 순서대로 카테고리를 추가한다.
3. 각 기술의 이름과 배경/글자 HEX 값을 입력한다.
4. 미리보기에서 글자 대비를 확인한다.
5. 페이지 아래의 저장 버튼을 누른다.
6. `/dev`에서 반영 결과를 확인한다.
