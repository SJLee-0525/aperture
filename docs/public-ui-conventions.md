# 공개 화면 UI 컨벤션

관리자 화면은 [admin-ui-conventions.md](admin-ui-conventions.md) 를 따른다. 이 문서는 방문자가
보는 화면의 규칙이다. 지금까지 이 규칙들은 `src/app/globals.css` 주석에만 있었고, 새 화면을
만드는 사람이 그 파일을 열어 보기 전에는 알 수 없었다.

## 지면 열

공개 지면의 폭은 `--page-max`(1180px) 하나다. 헤더·푸터·본문·상세 히어로가 같은 선에서
시작해야 한다.

- 본문 열은 `.u-page-main` 유틸리티를 쓴다. 폭·가운데 정렬·상하 여백이 함께 온다.
- 로딩 셸은 `.u-loading-shell` 을 겹쳐 첫 화면 높이에서 자른다. 스켈레톤이 실제 화면보다
  길면 그만큼이 스크롤로 남아, 데이터가 도착할 때 지면이 줄어든다.
- 폭이 다른 지면(연락 980px, 법적 문서 860px, 검색 820px)은 자기 모듈에 적는다.

CSS 모듈 클래스와 유틸리티를 한 요소에 함께 얹을 때는 **같은 속성을 양쪽에서 선언하지
않는다**. 클래스 하나짜리 셀렉터는 명시도가 같아 승자를 스타일시트 삽입 순서가 정한다. 그
순서는 라우트 진입 경로에 따라 뒤집힌다.

**라이브러리가 붙이는 클래스도 같은 상대다.** maplibre 는 지도 컨테이너에 `.maplibregl-map`
(`position: relative`)을 직접 단다. 같은 요소의 모듈 클래스가 `position: absolute` 를 선언하면
둘이 다투고, relative 가 이기는 순간 `inset` 이 무시돼 요소 높이가 0 이 된다. maplibre 는
높이 0 을 `clientHeight || 300` 으로 받아 캔버스를 300px 에 고정하므로 지도가 잘린 채 남는다.
라이브러리가 소유하는 속성은 넘겨주고 크기만 정한다.

## 스크림 세 층

겹치는 오버레이일수록 아래를 강하게 덮는다. 값은 `globals.css` 의 토큰이다.

| 토큰 | 값 | 쓰는 곳 |
| --- | --- | --- |
| `--scrim` | 0.55 | 모달·바텀시트 |
| `--scrim-strong` | 0.66 | 사진 상세 |
| `--scrim-stage` | 0.82 | 이미지 라이트박스 |

전면 `backdrop-filter` 는 한 번에 한 겹만 그린다. 두 오버레이가 전환 중 겹치는 구간에서는
아래쪽만 스크림을 갖는다. 두 겹을 합성하면 전환 프레임이 떨어진다.

## 포커스 링의 소유권

기본 링은 `globals.css` 한 곳이 정한다. `:where()` 로 감싸 특이도가 0 이므로 컴포넌트가
자기 링을 선언하면 그쪽이 이긴다.

CSS 모듈에 남아 있는 `focus-visible` 선언은 47개다. 정당한 오버라이드는 두 부류뿐이다.

1. **어두운 배경 위 크롬** — 사진 상세·라이트박스·지도처럼 배경이 사진이라 액센트 대비가
   보장되지 않는 자리. 흰 링으로 덮는다.
2. **모양이 다른 컨트롤** — 칩·토글처럼 바깥 여백이 없어 `outline-offset` 을 줄여야 하는 자리.

그 밖의 이유로 링을 다시 선언하지 않는다. 특히 `outline: none` 은 대체 표시를 같은 규칙에
적지 않는 한 쓰지 않는다.

## 화면에서 감추고 낭독기에 남기기

전역 `.sr-only` 를 쓴다. `display: none` 과 `visibility: hidden` 은 접근성 트리에서도 빠져
쓸 수 없다. 기법은 `clip-path: inset(50%)` 이며, 폐기된 `clip: rect()` 를 새로 쓰지 않는다.

로컬 모듈에 같은 규칙을 다시 적지 않는다. 한때 일곱 벌이 있었고 그중 여섯이 폐기된 기법을
쓰고 있었다.

## 본문 건너뛰기 링크

`(public)/layout.tsx` 가 `#page-content` 로 가는 링크를 첫 요소로 둔다. 클래스는
`sr-only u-skip-link` 이며, 포커스를 받을 때만 화면 왼쪽 위에 나타난다. 각 지면은 본문
컨테이너에 `id="page-content"` 를 유지해야 한다.

## 색과 간격

`globals.css` 의 `:root` 변수만 쓴다. hex 를 직접 적지 않는다. 다크 모드는 `[data-theme]`,
섹션 액센트는 `[data-section]` 셀렉터가 값을 바꾸므로, 컴포넌트는 항상 `--accent` 계열
변수만 참조한다.

## 그리드 경계

사진 그리드의 열 경계는 `constants/breakpoints.ts` 의 `PHOTO_GRID_BREAKPOINTS` 가 정한다.
`next/image` 의 `sizes` 와 `matchMedia` 질의가 거기서 파생한다. CSS 는 상수를 읽을 수 없어
`PhotoGrid.module.css` 의 미디어 쿼리에 같은 숫자가 남는다. 한쪽을 바꾸면 다른 쪽도 바꾼다.
